# 评委视角自检清单（打开演示地址后逐条打勾）

> 定位：**评委亲自打开在线演示地址**时，用来判断「这套系统到底能不能用」。
> 与 `docs/部署后自检清单.md`（部署者视角，偏 Docker/服务器）互补：
> 那份回答「装得对不对」，这份回答「用起来对不对」。
>
> 每条都写明：**点哪里 → 应看到什么原文 → 多久算正常 → 看到什么就判不通过**。

---

## §0 打开首页（0–10 秒）

**操作**：打开部署地址，等待加载。

| 应当看到 | 判不通过 |
|---|---|
| 左侧边栏出现 **9 个导航项**，依次含 🤖、📁、💬、📖、🔍、🕸️、✍️、🏗️、💡 | 侧边栏空白 / 少于 9 项 |
| 默认落在「🤖 Agent 总助手」页 | 直接 500 错误页 |
| 页面无任何红色 traceback | 出现 `Traceback (most recent call last)` |

**时间基准**：首次冷启动含依赖与模型加载，最长约 **3–8 分钟**；之后刷新应在 **10 秒内**。

> ⚠️ 若**持续转圈超过 8 分钟**：优先排查 `HF_ENDPOINT`（见部署手册 R2），
> 云平台在境外时指向国内镜像会让 embedding 首次下载卡死。

---

## §1 一键加载演示数据（第 1 个必点按钮）

**操作**：左侧边栏最下方 → 点 **「🚀 一键加载演示数据（v1/v7/BERT）」**。

| 应当看到 | 判不通过 |
|---|---|
| 文献库出现 **3 篇论文**（1706.03762v7 / 1810.04805v2 等），卡片带年份与页数 | 文献库仍为空 |
| 提示中出现「语义查重命中」或入库成功类文案 | 弹出未捕获异常 |
| 侧边栏显示已加载状态 | 卡住不动超过 60 秒 |

**时间基准**：本地已缓存约 **数秒**；云上首次含 PDF 解析，约 **10–40 秒**为正常。

> 无 API Key 也能加载成功——演示数据就在仓库的 `demo_data/` 里。
> 若提示「demo_data 不存在」，说明该目录未入库（本轮已核实：3 个文件均已 tracked）。

## §2 问一个问题（验证抗幻觉全链路）

**操作**：切换到「💬 问答与溯源」→ 输入问题（如「Transformer 的核心结构是什么？」）→ 点提问。

| 应当看到 | 判不通过 |
|---|---|
| 答案正文带 **【n】角标**，且角标指向底部来源列表 | 答案无角标 |
| 底部有「参考来源」列表，含页码 | 来源列表为空 |
| 出现「✅ 引用校验通过」之类标识 | 出现「以下内容未在来源文本中找到对应依据」噪声 |
| 若 Key 失效：出现**人话**提示 + 「离线演示仍可用」指引 | 直接抛出 traceback |

**时间基准**：`glm-4-flash` 常规 **2–8 秒**；超过 **25 秒**会走预算截断并降级占位。

## §2.5 九个页面逐个点（全链路无红线）

按顺序点开侧边栏 9 项，每项**都应打开且无 traceback**：

| # | 页面 | 进去后应当能看到 |
|---|---|---|
| 1 | 🤖 Agent 总助手 | 任务输入框 + 执行按钮；无 Key 时给出「Agent 执行需要大模型」的人话提示 |
| 2 | 📁 文献库管理 | 论文列表；空库时提示「📭 文献库为空。请先在左侧点击「🚀 一键加载演示数据」」 |
| 3 | 💬 问答与溯源 | 提问框 + 来源列表 |
| 4 | 📖 版式阅读与翻译 | PDF 页渲染 + 翻译面板 |
| 5 | 🔍 检索与追踪 | 检索框 + 追踪配置 |
| 6 | 🕸️ 引用图谱与综述 | 图谱构建入口（build_citation_graph）|
| 7 | ✍️ 写作辅助与可视化 | 写作框架 + 示意图生成；可载入 `demo_data/data.csv` |
| 8 | 🏗️ 系统架构 | 分层架构图（不依赖外部 CDN）|
| 9 | 💡 创新亮点 | 创新点说明 |

**判不通过**：任一页面出现红色错误框、`Traceback`、或长时间空白。

## §3 时间基准汇总（评委可直接对照）

| 动作 | 正常耗时 | 超过即判异常 |
|---|---|---|
| 首页冷启动（云上首次） | 3–8 分钟 | > 8 分钟 |
| 页面刷新 | < 10 秒 | > 30 秒 |
| 一键加载演示数据（云上首次） | 10–40 秒 | > 60 秒 |
| LLM 问答 | 2–8 秒 | > 25 秒（会降级占位） |
| 构建引用图谱 | 视文献量，通常 < 30 秒 | > 2 分钟 |

---

## §4 已知会出现的「正常提示」（别误判为故障）

| 文案 | 含义 |
|---|---|
| 「📭 文献库为空。请先在左侧点击「🚀 一键加载演示数据」」 | 正常空态，不是报错 |
| 「🔌 测试连通性」未通过 | Key 未配置或额度问题，非系统故障 |
| 「⚠️ 离线占位响应：LLM 不可用，以下内容不是模型生成」 | 诚实降级，系统设计如此 |
| 「语义查重命中：库中已有《…》，内容相似度 100.0%」 | 重复入库保护生效 |

---

## §5 若评委环境无网络 / 无 Key

仍可完整演示的链路：**本地 PDF 解析 → 版面感知切分 → 混合检索（BM25 + 向量）→ 引用图谱构建**
—— 点「🚀 一键加载演示数据」后使用 📁 / 💬 / 🕸️ 页面即可，不依赖外网。
