## 一、录制规格与全局纪律

### 1.1 技术参数（一次性设好，不要每段改）

| 项目 | 取值 | 理由 |
|---|---|---|
| 分辨率 | **1920 × 1080** | 假定基准；不追 4K，文件过大不利上传 |
| 帧率 | **30 fps 恒定帧率** | 务必"恒定"，变帧率后期拼接必然音画不同步 |
| 编码 / 封装 | **H.264 / MP4** | 兼容性最好 |
| 码率 | 8–12 Mbps | 7 分钟约 450 MB 以内 |
| 音频 | AAC / 48 kHz / 单声道 / 160 kbps | 旁白为主，不需要立体声 |
| 捕获源 | OBS **窗口捕获 → 浏览器窗口** | 不录桌面、不录任务栏、不录微信弹窗 |
| 字幕 | 全程中文字幕（后期上**独立字幕轨**，不烧进画面） | 烧进去裁切时要重编码；独立轨可随片长调整 |

### 1.2 鼠标纪律（比现场更严——镜头会放大每一次乱晃）

1. **每个按钮点击前：先匀速移动到目标，悬停 1.0 秒，再点击。** 悬停这一秒是后期加"点这里"箭头标注的唯一机会。
2. **移动走直线，匀速，单次移动控制在 0.6–1.0 秒。** 不要甩、不要抖、不要画圈。
3. **不操作时，鼠标停在屏幕中央区域（主体区，约 x 1000 / y 500）不动。** 不要停在侧边栏上——那里会悬停触发工具提示。
4. **不用鼠标滚轮做无关滚动。** 需要滚动的地方（节点 4 同步滚动、节点 5 下滚指标表）脚本里会写明。
5. **开启鼠标高亮工具**（推荐 PointerFocus / CursorHighlight），**光标环 + 点击涟漪全片保持开启**。

> **判定方式**：每段录完**立即回看一次**（回看只看下面这些判据，不用看全片），命中"必须重录"任一条 → **整段重录**，
> 不要试图在后期剪掉——后期剪掉往往会把前后旁白接缝露出来。

### 4.1 必须重录（R 类，命中任意一条 → 该节点整段重录）

| # | 触发条件（可判定阈值） | 判定方法 | 处置 |
|---|---|---|---|
| **R1** | **模型调用首字出现 > 10 秒**，或 spinner 累计转圈 > 15 秒 | 回看时秒表计时；节点 3 答案、节点 6 图注/框架适用 | 整段重录；先确认 Key 有效再录 |
| **R2** | 画面出现**橙色「⚠️ 离线占位响应」横幅**，或主体区底部出现**框架横幅「⚠️ 大模型调用失败」** | 一眼可见的橙色/红色条 | 整段重录。**不要用"这是我们的降级设计"之类的话术把它掩盖过去**——视频会被逐帧复审，降级画面藏不住 |
| **R3** | 出现**红色错误框 / 追溯栈 / Traceback**，或**整页白屏 > 3 秒** | 一眼可见 | 整段重录；若复现两次，先查 `logs/errors.log` 再录 |
| **R4** | 上传 v1 后**没有出现黄色查重预警框** | 节点 2 第 3 格录完后立即看 | 整段重录；先核对 v7 先入库、v1 后上传的顺序 |
| **R5** | 版本差异报告**标题是"已降级为离线对比"**，或页面上出现「⚠️ 版本差异报告已降级：大模型暂不可用，未生成对比表格。」（`ui/page_library.py:591`） | 节点 2 第 4 格 | 整段重录。**这是 `docs/演示彩排脚本.md` 里 E1b 描述的那个场景：画面上没有任何橙色横幅，只有一份标题写着"已降级"的报告，极易漏判** |
| **R6** | 双栏检测结果出现**蓝色「📄 单栏（文本块 N 个，未发现 ≥ 12pt 中缝）」** | 节点 4 第 2 格（`ui/page_reading.py:1307`） | 整段重录；通常是选错 PDF 或页码没改成 3 |
| **R7** | 图谱出现**「⚠️ 未检测到文献间的真实引用关系，已生成仅含节点的图谱。」**（`ui/page_graph.py:237`）或「📭 未检测到引用边（孤立节点图谱仅展示图论指标）。」（`ui/page_graph.py:180`） | 节点 5 第 1 格 | 整段重录；**不要在正片里点「🎭 演示模式示意图谱」兜底** |
| **R8** | 写作页 References 溯源区出现**红框「📭 本次没有可用的真实文献（文献库为空或 PDF 未抽出 References 段）」** | 节点 6 第 3 格 | 整段重录；说明前面的入库失败了，先修库再录 |
| **R9** | 检索三通道**任一 8 秒无响应**或出现「⚠️ …（网络受限）」提示 | 节点 7 两格 | 整段重录，或改用第三节"整段替代方案"（静态复述镜头） |
| **R10** | 画面中**任意一帧出现**：Key 输入框、`.env` 文件、终端、API 对话内容。出现 > 1 帧即判定 | 全片扫帧 | 整段重录 |
| **R11** | 音轨出现**口头禅**（嗯/啊/那个/然后/就是）**累计 ≥ 2 次**，或**卡壳 > 3 秒**，或口播里夹了第三节禁用英文术语 | 回放听；同时校正字幕 | **补录该句**（不必整段），补录时连带前后各 2 秒做接缝 |
| **R12** | 某一格**画面完全静止 > 12 秒**且无任何 spinner/进度条 | 回看计时；常见于节点 2 第 4 格、节点 6 第 3 格 | 补录或按第二节的缓冲点裁掉该段空白 |
| **R13** | **音画不同步 > 0.3 秒**，或录制帧率**掉到 < 25 fps 累计 > 3 秒** | 播放器看口型；OBS 日志看掉帧 | 整段重录；多半是编码器/磁盘问题，先录 30 秒试片 |

### 4.2 可容忍（T 类，留着不重录，后期处理即可）

| # | 容忍条件（阈值上限） | 后期处理 |
|---|---|---|
| **T1** | **页面首次切换加载慢 ≤ 2 秒** | 保留；超过部分按第二节缓冲点裁掉 |
| **T2** | **点击后按钮置灰 ≤ 1.5 秒** | 保留，正常观感 |
| **T3** | **进度条停顿 ≤ 3 秒**（观感上仍在正常处理） | 保留；这里可加一条字幕"正在解析"填缝 |
| **T4** | 旁白某句**多说 1–2 秒** | 保留；直接在句末缓冲点收掉，或裁掉多余部分重接 |
| **T5** | 音轨掺入**一次 ≤ 0.5 秒的呼吸/清嗓声** | 保留；必要时后期降噪 + 音量包络压低 6 dB |
| **T6** | 界面上**版本号、日期、内存 MB 数**等非讲解对象数字与脚本不符 | 保留；**旁白不念这些数字即可** |
| **T7** | 图谱**节点坐标/连线走向**每次略变 | 保留；布局本身是力导向的，变化属正常 |
| **T8** | 检索返回的**结果条数**与脚本估算不同（同量级即可） | 保留；**旁白不报具体条数**，只讲机制 |
| **T9** | 逐段翻译耗时 **10–20 秒** | 保留；正好填满第二节的 4 秒缓冲 + 少量等待，加一条"正在翻译"字幕 |
| **T10** | 鼠标落点**偏离按钮中心 ≤ 15 px**（仍然命中） | 保留；> 15 px 会显得手抖，重录该格 |
| **T11** | 帧率**瞬时抖到 26–29 fps 且 ≤ 2 秒** | 保留 |
| **T12** | 界面上「📚 文献库 N 篇 · M 个片段」的**数字与脚本写的 2 篇不同** | 保留；**旁白不念数量**，把"库里已有两篇"改成"库里已有预先入库的论文" |
| **T13** | 翻译结果走了会话缓存，画面出现「♻️ 已恢复上次的翻译结果」灰字 | 保留；这正是"已预跑"的证明，不是故障 |

### 4.3 判据优先级

> **R 类与 T 类冲突时，一律按 R 类处理。**
> 例：版本差异走了离线降级——T13 看起来像"缓存正常"，但它同时命中 **R5**（标题写着"已降级"），**必须重录**。

## 六、录制方式与后期拼接建议

### 6.1 推荐：分段录（九个节点各录一段，最后拼）

| 优点 | 缺点 |
|---|---|
| 某段 NG 只重录这一段，不用从头再来 | 需要保证九段的**界面状态、鼠标位置、语速**完全连贯 |
| 可以等模型出结果再开录，避免长留白 | 拼接处若不注意会露出"跳一刀" |

**分段录的三条铁律**
1. **每段开头多录 2 秒静止帧、结尾多录 2 秒静止帧**，作为拼接余量。
2. **每段开录前的鼠标起始位置 = 上段结束时的鼠标位置**，逐段记在纸上。
3. **每段录完后立即回看**，对照第四节 R 类 13 条打勾，不合格当场重录——**不要攒到最后一起看**。

### 6.2 备选：一镜到底

> 只在**操作足够熟练、九段全部预跑通过、环境绝对安静**时使用。
> 一镜到底的好处是零接缝，坏处是任何一处 NG 都要整片重录。
> **采用一镜到底时，第二节每格结尾的留白绝对不能省**——那 1–5 秒是唯一能救命的地方。

### 6.3 音频：建议先录语音、后配画面

1. 拿第二节的"旁白"列单独录一遍纯语音（逐格录，卡了就重录这一句）。
2. 把音轨铺进时间线，按音轨长度反推每格画面该留多少秒——**哪一段语音有多余空白，就在那段延长静止帧**。
3. 最后用这条干净的音轨替换录屏原声。**这样口播一定比边操作边说流畅得多**，也不会有口头禅。
4. 字幕按这条最终音轨生成，**不要按录屏原声生成**（两者可能不一致）。

### 6.4 超时 / 不足时的全局削减与补录顺序

| 顺序 | 削减项 | 省出 | Tier |
|---|---|---|---|
