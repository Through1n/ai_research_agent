# 作品提交与推送操作指南（照着做即可）

> 适用：全国高校 AI 大模型挑战赛 · 省赛提交（截止 2026-11-18）
> 本机 Git 已装在 conda 环境：`C:\Users\Administrator\anaconda3\envs\ai_research\Library\bin\git.exe`
> 以下命令都在 `C:\Users\Administrator\ai_research_agent` 目录下、PowerShell 中执行。

---

## 第 0 步：把提交作者改成你本人（必做，一次性）

当前仓库提交作者还是占位符，GitHub 页面会显示它。先改：

```powershell
$git = "C:\Users\Administrator\anaconda3\envs\ai_research\Library\bin\git.exe"
& $git config user.name  "你的姓名或GitHub用户名"
& $git config user.email "你的邮箱@example.com"
# 重写已有 11 个提交的作者（本地仓库未推送过，安全）
& $git -c user.name="你的姓名或GitHub用户名" -c user.email="你的邮箱@example.com" rebase --root --exec "git commit --amend --no-edit --reset-author"
```

## 第 1 步：注册并创建远程仓库

1. 注册 [github.com](https://github.com)（或国内更快的 [gitee.com](https://gitee.com)）。
2. 网页上 New repository → 名字如 `ai4s-research-agent` → **Public** → 不要勾选自动 README/License（本地已有）。
3. 复制仓库地址，形如 `https://github.com/你的用户名/ai4s-research-agent.git`。

## 第 2 步：推送

```powershell
& $git remote add origin https://github.com/你的用户名/ai4s-research-agent.git
& $git push -u origin main
```

弹出登录时：GitHub 需用 **Personal Access Token**（Settings → Developer settings → Tokens → 勾选 repo 权限），不是账号密码。Gitee 直接用账号密码。

> 推送约 24MB，含官方测试 PDF，属正常范围。若网络超时，可分批：`git push origin main --thin` 或改用 Gitee。

## 第 3 步：推送前最后自查（已替你做完，供复核）

- ✅ 全仓库与全部历史已扫描：无 `.env`、无 API Key 明文（密钥仅经环境变量/侧边栏注入）
- ✅ README 含项目介绍、技术架构、安装运行指南、团队信息（**队名/组别/成员/指导教师四处空位记得填**，README 末尾与技术文档封面各一处）
- ✅ Git 提交历史 11 条，按模块分主题，体现真实开发过程
- ✅ requirements.txt 版本锁定 + .env.example + Dockerfile + docker-compose.yml 齐全

## 第 4 步：在线演示部署（评审期间保持可用）

三选一，按成本从低到高：

| 方案 | 做法 | 注意 |
|---|---|---|
| A. 自己的电脑常开 | 路由器映射 8501 端口或用内网穿透（如 cpolar/ngrok 免费版） | 演示期间电脑不能关机；提供测试账号说明 |
| B. 云服务器 | 任意国内轻量服务器装 conda 环境 → `docker compose up -d` | 需在 .env 填入你的智谱 Key（服务器上环境变量注入，不进仓库） |
| C. 容器平台 | 阿里云/腾讯云 WebIDE 或容器服务部署 Dockerfile | 注意免费额度 |

Streamlit 无内置登录，若担心乱改数据：演示库用「一键加载演示数据」即可恢复；侧边栏「清空文献库」按钮就是重置入口。

## 第 5 步：录视频（见 docs/演示视频脚本.md）

- 5–8 分钟、MP4、1080p、普通话；脚本含逐段台词与录制检查清单
- 录前跑一遍 `python scripts/apptest_check.py` 确认全绿

## 第 6 步：官网提交清单核对

| 材料 | 状态 |
|---|---|
| GitHub/Gitee 仓库（Public） | 完成第 1–2 步后即有 |
| 演示视频 MP4 | 按脚本录制 |
| 技术文档 PDF（≤30 页） | `docs/技术文档.pdf`（19 页，**填上封面组别/队名**） |
| 在线演示地址 + 体验账号 | 第 4 步 |
| 大赛官网统一提交入口 | 缴费后个人中心查看 |
