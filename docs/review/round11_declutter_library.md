## 一、结构改造

原来：5 个区块用 `st.markdown("---")` 串成一条长页面 + 顶部健康诊断区。
现在：`st.tabs` 三个页签（tab 名不带 emoji）。

| 页签 | 内容 |
|---|---|
| 上传与解析 | 库健康诊断（原位，仍在上传器上方）→ 上传 PDF + 语义查重决策 → 元数据与排版识别 → 细粒度结构解析 |
| 文献库 | 当前文献库一览 + 删除 |
| 版本差异 | 多版本分组 + 差异对比 |

健康诊断放在「上传与解析」而非「文献库」的原因：它原本就在上传器上方，且文案里含
「用**下方**按钮一键重建」的相对方位——挪到别的页签会让这句话失真。放在原位置是唯一
不需要改这句告警文案的排法。

## 五、顺带修正的方位文案（4 处，非降级文案）

改 tabs 后「上方 / 下方」会指向错误的页签，仅把方位改成页签名，语义不变：

3. 元数据两处 info：`见下方「📚 当前文献库」/ 见下方文献库列表` → `见「文献库」页签`。
4. 文献库空态 hint：`或在上方上传 PDF` → `或在「上传与解析」页签上传 PDF`。
5. 降级说明里的 `下方「💡 建议保留最新版」` → `「建议保留最新版」`（因该 caption 去掉了 💡 前缀）。
