## 5. 不确定处 / 需要复核

1. **`elif toc:` → `elif not toc:`**：为了让「内置书签 N 条」这条 caption 消失，标题树的三分支改成了两分支（`inferred` → 提示；`not toc` → 无目录提示；有内置书签 → 不显示提示）。语义与原来完全等价（原分支在有书签且非推断时只显示那句被删的 caption），但**改动了条件写法**，请复核一眼。
2. **删掉两处性能遥测（峰值内存 / 耗时 / 并发数）**：用户侧信息量有损失。若评审认为这类「工程化透明度」是本项目卖点，这两条可以很容易撤回（一处 caption、一处 info）。
3. **`stale` / `peak` 局部变量**：`_long_doc_scan` 里 `cleanup_stale_figure_dirs(...)` 的**调用保留**（清理行为不变），只是不再把 `stale` 打印出来，`peak` 变量也不再被 f-string 使用。两处赋值没删，避免动到逻辑；若要求零未使用变量可以再清。
4. **`probe` 在引用跳转分支**：`_new_probe("引用双向跳转")/probe.start()` 仍在，只是不再输出峰值内存与耗时（其余 `probe.sample()` 未动）。
5. **基线归因**：12→3 这个数字里，有一部分是 sidebar.py 同期改动带来的；我能确认的是「阅读页自身可见 caption 现在 = 3 条」。若要严格逐文件基线，需要用 HEAD 版本单独跑一次度量（我未做，避免动工作区状态）。
