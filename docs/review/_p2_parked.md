### 防线零：范围锁定（把检索域先圈住）

这一条此前散落在 2.2 ② 与 4.4，未单列；它其实是**走在其他三道防线之前**的前置约束——先把"可以去哪些文献里找答案"圈死，再谈相关度与引用校验。

- **入口**：`services/rag.py:502 retrieve(..., source_filter=...)`，docstring 原文即"传入论文文件名时只在该篇内检索（单篇范围锁定）"，问答页与 Agent 工具 `qa_paper` 都经此参数进入。
- **实现要点**：`services/rag.py:520-523` 在锁定单篇时**先把 `dense_k` / `sparse_k` 放大到 `final_k × 3` 再过滤**（`:563-564` 对 dense 结果按 `chunk["source"]` 过滤、`:548` 对 sparse 结果由 `sparse_search(..., source=source_filter)` 过滤）。这一步不能省——若先截断再过滤，锁定单篇后候选会不足，反而制造"明明这篇里有答案却拒答"的假阴性。
- **与来源多样性截断的相互作用**：`services/rag.py:290` 明确"单来源池（`source_filter` 锁定单篇 / 库内仅一篇）**不截断**，仅按相关度分数降序重排"。即范围锁定时 `cap_by_source` 的同来源抑制逻辑自动让位，否则会把用户指定的那一篇把自己的结果削掉。
- **抗幻觉价值**：跨文献问答若不做范围锁定，模型可能拿 A 论文的细节去答 B 论文的提问而仍"看起来有出处"（角标合法、内容张冠李戴）；把检索域锁死在用户指定的那一篇，可以从源头消除这类**跨文献串引**。
