# 5 分钟快速体验指南（评委专用）

> 目标：**从打开材料到看到第一个回答，5 分钟以内。**
> 全程**不需要注册账号、不需要登录、不需要自备 API Key**。
>
> 三件事先说清楚，省得中途怀疑自己是不是搞错了：
>
> | 你可能担心的 | 实际情况 |
> |---|---|
> | 要不要装 Python / 配环境？ | **第 1–3 分钟完全不用装任何东西**，浏览器打开就能看 |
> | 要不要注册、要不要登录？ | **都不用**。系统为开放式访问，没有任何登录鉴权逻辑 |
> | 要不要自备智谱 / OpenAI 的 Key？ | **不用**。点一下「一键加载演示数据」，离线链路全部可用 |

## 第 3 分钟 · 点开在线演示地址看真系统

1. 打开**在线演示地址**：**https://ai4s-research-agent.app.workbuddy.host/**
   （已部署；WebSocket 跨源与冷启动两项线上访问问题已定位并修复，重部署后需复验。
   备用 streamlit.io 域名按 `docs/部署操作手册.md` 五步另行部署后替换）
2. **不需要账号，不需要 Key**。
3. 如果打开后**页面全白**：本项目实测遇到过两个根因——① WebSocket Origin 校验 403、
   ② 冷启动时 embedding 模型下载堵死首帧——**两者均已修复**。线上首帧依赖模型就绪，
   冷启动首次可能需要数十秒，请耐心等首帧；**判据是看浏览器右上角有没有 `Stop` 按钮**：
   有 `Stop` = 脚本还在跑，不是坏了；没有 `Stop` 却一直全白，请改走第 4 分钟的本地路径
   （`start.bat` / `start.sh` / Docker），并把现象反馈给队伍。
4. 进去后第一件事：左侧边栏拉到最底 → 点 **`一键加载演示数据（6 篇）`**
   → 看到 `✅ 演示数据已就绪，当前文献库 6 篇` 就成功了。

**这一分钟里建议你顺手点这三下**（都在左侧菜单，从上往下）：

| 点这里 | 应该看到 |
|---|---|
| 文献库管理 | 6 篇论文条目，带页数 / chunk 数 |
| 跨文献问答与溯源 | 输入问题后给出带来源的答案卡片（无 Key 时走本地召回） |
| 引用图谱与综述 | 点 `🎭 演示模式示意图谱` 出一张三节点以上的图 |

> 📌 在线演示跑的是和本地**完全同一份代码**，不是录屏，也不是静态原型。

## 第 4 分钟 · 本地 clone 跑起来（可选，验证可复现性）

这一步是给愿意在本机验证的老师准备的。**本机有 conda 就用 A / B，什么都不想装用 C。**

### A. Windows —— 双击即可

```bat
:: ① 拿到代码
git clone <仓库地址> ai_research_agent
cd ai_research_agent

:: ② 双击根目录的 start.bat（或命令行里敲）
start.bat
```

脚本会自动做完这些，**不用人工干预**：

```
[1/5] 定位项目根目录
[2/5] 检测 conda → 没有 ai_research 环境就自动创建（Python 3.11）
[3/5] 依赖不全就 pip install -r requirements.txt
[4/5] 检查 API Key（没有会提示，但不会拦你）
[5/5] 启动 streamlit run app.py 并自动打开浏览器
```

### B. macOS / Linux

```bash
git clone <仓库地址> ai_research_agent
cd ai_research_agent
chmod +x start.sh
./start.sh
```

### C. 有 Docker（最稳，一次成型）

```bash
docker build -f Dockerfile.quick -t ai4s-quick .
docker run --rm -p 8501:8501 ai4s-quick
# 这个镜像会在启动时自动加载演示数据，连按钮都不用点
```

浏览器会自动打开 **`http://localhost:8501`**；Streamlit 首次渲染要几秒预热，请稍等。

> ⚠️ 8501 端口被别的程序占了 → 脚本会**自动改用 8502**（依次试到 8510）并在黑窗口里告诉你跳到了哪个端口。

## 第 5 分钟 · 点「一键加载演示数据」，问一个问题

1. 左侧边栏 → 拉到最底部「🧪 演示与维护」区
   → 点 **`一键加载演示数据（6 篇）`**
   → 等你看到顶部绿色提示 **`✅ 演示数据已就绪，当前文献库 6 篇`**。

2. 左侧菜单点 **`跨文献问答与溯源`**，在输入框里问任意一个：

   > - `Transformer 的核心创新是什么？`
   > - `这篇论文解决了什么问题？用了什么方法？`
   > - `Attention is All You Need 和 BERT 有什么关系？`

3. **看懂屏幕上的三类信息**（这就是本系统区别于普通聊天机器人的地方）：

   | 看到的东西 | 说明 |
   |---|---|
   | **答案正文 + 引用角标** | 每一句结论都对应到具体文献片段 |
   | **来源卡片 / 溯源列表** | 可以回溯到原文第几页第几段，不是编的 |
   | **`⚠️ 离线占位响应` 橙色标识条** | **没有填 Key 时**会出现 —— 这是**抗幻觉红线**，明确告诉你「这段不是模型生成的，别引用」，而不是偷偷编一段 |

4. 再点 **`引用图谱与综述`** → **`🎭 演示模式示意图谱`**，看一眼引用关系图。

**5 分钟到此结束。** 到这里你已经完整看到了：文献解析 → 混合检索 → 可溯源问答 → 引用图谱这条主链路。

## 一分钟排障

| 现象 | 原因 | 处置 |
|---|---|---|
| 在线地址打不开 / 全白 | 冷启动首帧未到 / 网络 | 看右上角 `Stop` 按钮：有 = 脚本还在跑，等首帧即可；没有且持续超 60 秒 → 改用第 4 分钟的本地路径 |
| 点了「加载演示数据」很慢 | 首次要解析 PDF 并建立索引 | 正常，首次偏慢；模型已随包预置、不再发生下载，若持续无响应按上一行的 `Stop` 按钮判据处理 |
| `start.bat` 说「没有检测到 conda」 | 本机没装 conda | 装 Miniconda 后重跑；**或直接改用在线演示地址** |
| 黑窗口停在 pip 安装很久走不动 | 首次装依赖 | 正常，2–5 分钟；想加速可换清华 pip 源 |
| 浏览器开了但打不开页面 | Streamlit 还在预热 | 等 5 秒刷新一次 |
| 端口提示跳到 8502 | 8501 被占用 | 用黑窗口里给的新地址即可，**不是故障** |
| 页面提示「storage/ 目录不可写」 | Docker 挂载卷属主不对 | `chown -R 10001:10001 ./storage ./logs` 后重启 |
| 点了大模型按钮没反应 | 没填 Key | **预期行为**，会弹中文提示；离线链路不受影响 |
