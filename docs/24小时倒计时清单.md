## 附录 B · 一键自检命令块（T-12 跑一次，T-30 分钟前再跑一次）

在仓库根目录执行（Windows 用 Git Bash；路径按本机实际调整）：

```bash
cd /c/Users/Administrator/ai_research_agent   # ← 按你的仓库路径改这一处

echo "== 1. git 同步（应输出 0	0）=="
git rev-list --left-right --count origin/main...HEAD

echo "== 2. 敏感/内部文件未跟踪（应全部无输出）=="
git ls-files | grep -E "^\.env$|^storage/|^\.workbuddy/|secrets\.toml$"

echo "== 3. 交付物存在性（应全部列出）=="
ls docs/技术文档.pdf README.md start.bat start.sh Dockerfile.quick \
   streamlit_app.py .env.example .streamlit/secrets.toml.example \
   docs/提交前必办清单.md docs/团队信息.md docs/演示视频脚本.md

echo "== 4. PDF 页数（应 ≤30）=="
python -c "import re;d=open('docs/技术文档.pdf','rb').read();print(len(re.findall(rb'/Type\s*/Page\b(?!s)',d)))"

echo "== 5. 视频是否就绪（有输出=已录制；无输出=仍是待办）=="
find . -iname '*.mp4' -not -path './dist/*' -not -path './build/*'

echo "== 6. 占位符残留（跑专用校验器，退出码 0=填完；1=仍有占位，按输出逐行填）=="
python scripts/_check_placeholders.py; echo "退出码: $?"

echo "== 7. 在线演示健康检查（应输出 ok）=="
curl -s https://ai4s-research-agent.app.workbuddy.host/_stcore/health; echo

echo "== 8. GitHub 可达性（应输出 200）=="
curl -s -o /dev/null -w '%{http_code}\n' https://github.com/Through1n/ai_research_agent
```

> 注：第 6 项的校验器 `scripts/_check_placeholders.py` 白名单只豁免格式示范文字，命中数会在汇总里明示，可审计；它同时输出每个占位的「文件:行号」，可直接照着填。
