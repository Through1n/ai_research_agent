**本段操作红线（本段改动最大，务必看清）**
- **图谱里没有红线，也没有版本演进连线。** 所有引用边都是同一种灰色箭头；节点只有三种配色：
  橙色五角星（基石）、蓝色圆点（核心）、灰色圆点（边缘衍生）。旁白**不要**说"红线代表版本演进"。
- **版本维度的真实行为是"合并"而不是"连线"**：同一编号的初版与第七版会被合并成**一个**逻辑节点，
  只取最新版参与计算，避免同一篇论文被重复计数。**这句话要念出来**，它是本段的技术亮点。
- 若页面提示「⚠️ 未检测到文献间的真实引用关系」，立刻点「🎭 演示模式示意图谱」兜底，
  并把界面上"当前为演示模式示意图谱，不代表真实引用关系"这句水印**念出来**——诚实标注是加分项。
- 预跑时库里有 BERT 与第七版，通常能建出一条真实引用边（BERT 引这篇论文）；建不出就走兜底。

## 五、录制技术参数建议

| 项目 | 建议值 | 说明 |
|---|---|---|
| 分辨率 | **1920 × 1080**（1080p）及以上 | 赛题硬指标"不低于 1080p"。显示器是 4K 也按 1080p 录，4K 文件过大不利上传 |
| 帧率 | **30 fps（恒定）** | 60fps 文件翻倍但评审看不出差别；务必选"恒定帧率"，否则后期拼接会音画不同步 |
| 编码器 | **H.264（AVC）** | 兼容性最好。H.265 体积小但部分评审机器放不了 |
| 封装/格式 | **MP4**（`.mp4`） | 赛题硬指标 |
| 码率 | 8–12 Mbps | 1080p30 下细节足够，8 分钟约 500MB 以内 |
| 音频 | AAC，48kHz，单声道，128–192 kbps | 旁白为主，不需要立体声 |
| 色彩 | 全屏 `F11`，浏览器缩放 100% | 保证图标与按钮文字不糊 |
