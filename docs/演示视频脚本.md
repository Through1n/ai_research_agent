# 演示视频脚本（5–8 分钟 · 普通话讲解 · 1080p）

> 录制前检查清单
> 1. `conda activate ai_research` → `streamlit run app.py`，浏览器 Ctrl+F5 强刷
> 2. 侧边栏填入 API Key（建议提前测一次问答，确认网络稳定）
> 3. 文献库保持**已清空**状态开场（点 🗑️ 清空 → 演示时点 🚀 一键加载，效果最好）
> 4. 录屏软件 1080p、系统音量静音（避免通知声）、鼠标移动放慢
> 5. 全程不要离开演示顺序；若某步失败，跳过即可，剪辑时删除该段

## 录制技巧
- **一次一段**：每个时间段单独录，出错只重录该段，最后拼接，别追求一镜到底。
- 问答与翻译若网络慢，先本地预热跑一次相同问题（结果进历史，录制时直接展示历史+重问一条快的）。
- 图谱页务必用**演示模式**兜底，防止现场 API 抖动。
- 讲解语速约每分钟 220 字，上面台词按此校准；卡词就停顿，后期可剪。
- 导出 MP4、1080p 以上；片头 3 秒加标题卡「AI4S 科研助手 · 全国高校 AI 大模型挑战赛参赛作品」。
