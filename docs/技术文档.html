1 项目概述

2026 年，大语言模型（LLM）与 AI Agent 技术引发了全球科学研究范式的深度变革，AI4S（AI for Science） 已从简单的文献摘要提取，跨越到能够自主进行文献阅读、逻辑推理、假设提出、实验代码生成乃至论文草稿撰写的 「AI 科学家助手」新阶段。然而，真实科研场景对学术规范、长上下文、复杂排版与「幻觉零容忍」的确定性要求， 使通用 Chatbot 远无法满足需求。

本项目面向真实科研全流程，从 0 到 1 设计并实现一款全栈式、具备自主规划与协同能力的 科研助手 Agent。系统以现代 Web 应用为形态，后端 Agent 通过任务规划、多专家路由与函数调用闭环， 自主调度文档解析、混合检索、学术 API、图谱计算与代码执行等工具，覆盖赛题要求的六大功能模块， 实现「文献导入 → 解析 → 问答 → 阅读翻译 → 检索推荐 → 图谱综述 → 写作输出」的完整闭环。

设计目标：高可靠（抗幻觉、可溯源）、自主化（Agent 规划与工具闭环）、 全流程（六大模块贯通）、可复现（容器化、一键部署）。

2 需求分析

2.1 科研痛点

痛点具体表现对应能力

创意落地与复现数据可视化、架构图、Idea 验证缺乏整合代码与 API 的工具代码执行、绘图、复现推荐

2.2 功能需求

系统须满足：输入素材可审查（稳定处理标准 PDF 与扫描件）；输出成果可验证 （解析、问答溯源、图谱节点、脚本与综述具备确定性与高复现性）；系统运行闭环 （完整前后端，可演示全流程）。功能上全面覆盖六大命题模块（详见第 5 章）。

2.3 非功能需求

  • 鲁棒性：支持扫描件、双栏、百页以上长文档，多文档并发分析不崩溃；
  • 性能：长 PDF 与 20+ 节点图谱渲染流畅，内存 / 显存可控；
  • 可复现：提供依赖清单、环境变量模板与 Docker 镜像，一键部署；
  • 安全性：API 密钥经环境变量隔离，具备提示注入防护与学术安全 Guardrails。

▼
Agent 内核 · Guardrails → Task Planning → Multi-Agent Router → Function Calling 闭环
Memory：短期对话 / 长期笔记 / 用户画像　|　Trace：思考过程可视化 / 流式
▼
工具 / 服务层 · PDF解析·OCR ｜ 混合RAG ｜ arXiv·PubMed·Web ｜ 图谱·图论 ｜ 写作·绘图·代码执行
▼
存储层 · Chroma 向量库 ｜ BM25 索引 ｜ library.json 元数据 ｜ 原始 PDF / 图片

3.2 Agent 运行数据流

① 输入自然语言意图
② 防护注入/密钥校验
③ 规划动态拆解 3–6 步
④ 路由6 类专家分流
⑤ 闭环函数调用执行
⑥ 溯源内联引用生成

Agent 内核采用「LLM 优先、规则兜底」策略：路由与规划优先由 LLM 以 JSON 输出，失败时退化为关键词路由与 固定步骤模板；工具执行采用原生 Function Calling + ReAct 文本解析双保险，最大迭代 8 轮， 超限则在无新增工具时强制总结，保证闭环可终止。

3.3 模块解耦

系统按 core / services / tools / ui / config 分包：core 仅负责推理与编排，services 封装 业务能力，tools 将 Python 函数统一注册为 OpenAI Function Schema，ui 仅负责渲染，依赖单向向下、便于测试与扩展。

4 AI 技术方案

4.1 模型选型与理由

类型选型选型理由
文本 LLM智谱 GLM-4-Flash（默认），可切换 DeepSeek / Qwen / GPT 等OpenAI 兼容协议、成本低、中文与工具调用稳定；免费额度友好，端点可经环境变量替换
多模态 / OCRGLM-4V，可扩展 Qwen2-VL / PaddleOCR / Marker处理扫描件与复杂版式，完成图文、公式、表格识别
EmbeddingChroma 内置 ONNX 向量模型（384 维）本地离线、免额外部署；支持 HF 镜像加速
Rerank可选 LLM 重排（编号排序）无需额外重排服务即可提升 top-k 精度

4.2 抗幻觉混合 RAG 与溯源

检索层同时维护稠密（Chroma 向量）与稀疏（BM25）两路召回，采用 RRF（Reciprocal Rank Fusion）融合排名：

RRF(d) = Σ 1 / (c + rank_i(d))      # c = 60，对稠密/稀疏两路排名求和后取 top-k

融合后可选 LLM 重排。生成阶段仅以编号资料构建上下文，系统提示强制使用 【n】 内联角标、 资料不足须明说、禁止编造；生成后校验角标范围，越界则触发一次自动修复。每条资料附带论文 ID 与页码锚点， 实现 Source Tracing。

4.3 多智能体路由与规划

Router 将意图分流至 6 类专家（问答 / 检索 / 图谱 / 写作 / 阅读 / 解析），各专家仅持有完成任务所需的 工具子集，降低误调用；Planner 将复杂任务动态拆解为有序步骤并交由执行闭环。

4.4 记忆与防护

  • Memory：短期对话历史、长期笔记 / 键值、基于领域计数的用户画像，为规划与个性化推荐提供上下文；
  • Guardrails：提示注入特征检测、输出密钥脱敏、引用角标校验、统一学术系统提示（学术安全与规范）。

4.5 函数调用与工具链

注册中心将 16 个 Python 工具封装为标准 Function Schema 并按名执行，涵盖文献检索、多文推理、 arXiv/PubMed/网页、下载入库、图谱构建、综述与前沿、写作框架、绘图、翻译、隔离 Python 执行与记忆读写。

5 核心功能实现

5.1 模块一：PDF 管理与细粒度解析

  • 语义去重：取正文前 4000 字生成论文级向量，通用查重阈值 0.90；并设版本规则——同一 arXiv 号且 相似度 ≥ 0.7 即判为不同版本（仍以语义为依据，非仅凭文件名），支持覆盖 / 保留 / 取消与版本差异总结；
  • 细粒度解析：结构化抽取标题、作者机构、摘要、三级标题树、表格、图表、LaTeX 公式、参考文献与附录；
  • 扫描件：自动检测文本层，缺失时判定 scanned 并逐页调用多模态 OCR。

5.2 模块二：抗幻觉问答与多文推理

单篇问答可定位超参数、GPU 型号数量、BLEU 分数、完整引用等细粒度信息并给原文锚点；多篇推理通过跨文档 Chunk 聚合，支持 BERT 与 Transformer 的承袭 / 抛弃、GPT-1/2/3 参数量演化、LayerNorm 位置与上下文窗口 递增等对比分析，答案内联 【n】。

5.3 模块三：版式阅读与双向联动翻译

  • 坐标级原生还原单 / 双栏版面（文字可选中），提取标题树导航；
  • 正文引用标记（如 [11]）与 References 条目双向无损跳转；
  • 中英对比采用 JS 按比例 + 段落对齐双机制实现真正同步滚动与悬停联动高亮，代码与公式保留英文； 支持划词 / 悬停翻译与整篇翻译。

5.4 模块四：检索、追踪与推荐

  • 给定标题 / 参考文献列表，经 arXiv / PubMed / 搜索引擎自动抓取并入库，支持批量下钻；
  • 引用含金量筛选，自动识别并建议剔除应付式引用；
  • 定期刷新追踪最新论文，结合本地库兴趣中心计算相关度，优先推荐附带 GitHub 开源代码（易复现）的论文， 提供推荐理由与点赞 / 踩互动。

5.5 模块五：引用图谱与综述

通过标题 token 滑动窗口重叠（≥0.8）+ arXiv 号出现判定论文间真实引用；在「逻辑著作」层建图 （同一 arXiv 号取最新版本为唯一代表节点，旧版本不产生孤立节点）。运用 PageRank、入度、中介与特征向量 中心性挖掘基石 / 边缘论文；基于图谱自动生成综述；提取各文 Future Work，按时间线比对后续论文摘要， 自动标注并排除已被解决的旧 idea，提炼真正开放的方向。

5.6 模块六：写作与可视化 Copilot

  • 依据 Idea 生成含 Abstract / Introduction / Related Work 的框架，References 仅引用本地真实文献， 不足处占位，杜绝幻觉引用；
  • 生成 Mermaid / TikZ / Graphviz / Matplotlib 架构拓扑图脚本；
  • 读取 CSV 自动生成折线 / 柱状 / 散点 / 三维雷达 / 热力 / 平行坐标图，并提炼符合学术规范的 Figure Caption；
  • 中文摘要 / 全文一键精准翻译为学术英文。

7 技术创新点

7.1 技术创新

  1. 真正的 Agent 架构：任务规划 + 多专家路由 + Function Calling 闭环，替代按钮式脚本，全程 Trace 可视化；
  2. 混合检索抗幻觉：BM25 + 向量 RRF 融合、可选 LLM 重排、内联角标 + 页码锚点 + 自动修复；
  3. 内容语义去重：论文级向量识别 arXiv v1/v7，同号版本规则 + 版本差异对比；
  4. 真实引用解析与图论挖掘：标题窗口匹配 + arXiv 号识别真实引用，PageRank/中心性定位基石论文；
  5. Future Work 前沿过滤：时间线比对后续论文，自动排除已解决的旧 idea；
  6. 双机制同步滚动：JS 按比例 + 段落对齐，悬停联动高亮，双栏坐标级还原。

7.2 应用创新

  1. 贯通科研全流程的单一 Agent 入口，自然语言意图驱动、零脚本操作；
  2. 复现导向推荐：优先带 GitHub 开源代码的论文，结合本地画像与点赞 / 踩反馈；
  3. 无幻觉写作：框架 References 只引用本地真实文献，显著提升学术产出可靠性。

8 总结与展望

本项目围绕真实科研痛点，完成了具备 Agent 内核、混合抗幻觉 RAG、多模态解析、真实引用图谱与学术写作 可视化能力的全栈科研助手，六大模块闭环贯通，并通过了语义去重、扫描件检测、长文档压测、真实图谱与全页面 渲染验证。

后续展望：① 接入更多开源 / 本地推理模型与专用 OCR 管线，降低成本与网络依赖；② 深化 Multi-Agent 协同与自我进化（基于反馈自动优化工具策略）；③ 扩展多用户协同推荐与云端部署；④ 增强实验代码自动生成与 结果复现，向端到端「AI 科学家」演进。
