## ② 换成真实可用的 API Key 🔴 演示生死线

**为什么**：当前 `.env` 里的 `ZHIPU_API_KEY` 是一个 **14 字符、含非 ASCII 字符的占位串**。
实测调用时直接返回：

```
【LLM 暂时不可用…'ascii' codec can't encode characters in position 7-13】
```

原因是中文字符无法写进 HTTP 请求头。**这意味着问答、翻译、写作、OCR 全部 LLM 功能
在演示时会全部失效**，而且扫描件 OCR 这一官方测试用例也因为拿不到 Key 而没能完成实测。

**怎么做**：
1. 去智谱（或你选的任意 OpenAI 兼容平台）申请真实 Key
2. 填入 `.env`，**必须是纯 ASCII**（英文+数字，不要有任何中文）
3. 确认 `.env` 仍在 `.gitignore` 里，**绝不能 push**（已确认 `.env` 从未进过 git 历史，放心）
4. 换完 Key 后，补测一次扫描件 OCR：
   ```bash
   conda activate ai_research
   python -u scripts/_verify_official.py --case A
   ```
