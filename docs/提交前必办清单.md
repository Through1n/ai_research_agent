**怎么做**（任选其一）：

```bash
# 方式 A：用 Personal Access Token（推荐）
#   1. GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic)
#   2. 勾选 repo 权限，复制 token
#   3. 执行：
git push https://<你的用户名>:<你的token>@github.com/Through1n/ai_research_agent.git main

# 方式 B：先配凭据再推
git config --global credential.helper manager
git push origin main      # 会弹窗让你登录，登录后自动记住
```

推完确认：`git status` 应显示 `Your branch is up to date with 'origin/main'`。
