### 10.2 我报错的触发场景（已修正）

我原先写"模型不可用 → 走 1222"，**在"完全没 Key"时不成立**——中间还有一道守卫：
`ui/page_library.py:580` 先跑 `llm_guard`（`ui/common.py:345`），而 `available`（`core/llm.py:457`）
是**静态**判 `self._client is not None`，**不探测网络**。

| 场景 | 实际行为 |
|---|---|
| 完全没 Key / Key 非 ASCII | `available=False` → llm_guard 拦截 → `version_diff` **根本不执行** → 显示「⚠️ 版本差异对比需要大模型，但未检测到可用 API Key。」✅ **正常** |

所以我给的复现步骤"把 API Key 置成无效串"是**错的**，那只走到 llm_guard。
正确复现需要**填一个格式合法但会失败的 Key**（或断网 / 触发 429），让 `available=True` 而调用失败。
**现场最可能撞上的是 429 限流**——Key 有效、额度在，但连续调用打满。
