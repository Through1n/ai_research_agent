## 三、`scripts/_check_placeholders.py` 设计

- 纯 Python 3 标准库（`re` / `sys` / `pathlib`），无第三方依赖；用法：`python scripts/_check_placeholders.py`
- 三类模式：`【占位符】`（含尾随下划线）、`\bTODO\b`、方括号组 `\[[^\[\]]*\]`
- 输出格式：`文件:行号 | 占位符原文 | 所属章节 › 行内标签`（章节取最近标题，行内标签取表格行首有效单元格或占位符前文字）
- 退出码：**0 = 无占位（可交付）/ 1 = 仍有占位 / 2 = 文件缺失**
- 白名单（脚本内显式列出并注释理由，非放任所有方括号）：
  `[ ]` 空括号（复选框 / 元引用）、`]` 后紧跟 `(` 的 Markdown 链接 / 图片文字、
  `[示例]` 示例标记、`XX大学` 类校名模板、`example.com` 类 IANA 保留域、纯数值参数列表；
  `[待填写]` / `[姓名]` / `[学校]` / `[组别]` / `[成员 N]` / `[____-__-__]` 等真实待填项一律拦截
- 白名单自测（临时文件，已删）：`[示例] 星链探索者`、`XX大学·计算机学院`、
  `captain@example.com`、`- [ ]`、链接文字、`[1.5, 3.0, 4.5]` 共豁免；
  `[待填写]`、`[姓名]`、`[2026-__-__]` 正确拦截
