## 二、七大模块与代码定位

> 本作品由参赛者个人独立完成，代码按赛题六大命题模块 + 交付工程分层组织。下表便于评委按模块查阅实现。

| # | 模块 | 关键文件入口 |
|---|---|---|
| ① | Agent 内核（任务规划 / 路由 / 记忆 / Guardrails / 沙箱 / Trace） | `core/`：`agent.py`、`planner.py`、`router.py`、`memory.py`、`guardrails.py`、`sandbox.py`、`trace.py` |
| ② | 多模态与细粒度文档感知（双栏判栏 / OCR / 语义去重 / 版本管理） | `services/parsing.py`、`services/library.py` |
| ③ | 抗幻觉 RAG（混合检索 / 引用校验 / 修复环） | `services/rag.py`、`services/query_expansion.py`、`core/guardrails.py` 校验部分 |
| ④ | 自主工具调用（Function Calling / 工具链） | `core/agent.py`、`tools/definitions.py` |
| ⑤ | 引用图谱挖掘与自动综述 | `services/graph.py`、`services/citation_quality.py` |

## 四、项目时间线

> 下表为本项目开发过程的阶段划分（时间以季节示意，不涉具体日期）；逐次提交记录见 Git 历史。

| 立项选题 | 2026 年初 | 明确 AI4S 痛点：文献解析串读、LLM 幻觉、离线不可用 | 需求清单、竞品对比表（README「功能矩阵」） |
