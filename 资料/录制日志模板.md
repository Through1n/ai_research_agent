# 演示视频录制日志模板

> **用途**：录制当场与每场结束时填写。它是**选片（挑最好的一条）和复盘唯一依据**——
> 不靠记忆，靠日志。配套文件：`资料/录制前检查清单.md`（开录前摆环境）、
> `资料/录制工程化脚本.md`（录什么、怎么说、多少秒；R1–R13 / T1–T13 判据）。
>
> **总时长口径**：按 `资料/录制工程化脚本.md` 的 **420 秒（7 分 00 秒）**，节点 0–9
> （节点 0 片头卡为静态图不进录屏）。**不要**拿 8:00（`资料/演示视频脚本.md`）或 7:30
> （`资料/演示彩排脚本.md`）的口径记时长——三份脚本时间轴不同，混记会导致选片时对不上基准。
>
> **填写纪律**：示例行一律带 `[示例]` 前缀，**不是真实录制数据**；自己填的时候把 `[示例]` 去掉。

## 四、选片决策：怎么按日志挑出最好的一条

> 每个节点可能录了多遍（T1、T2……）。按下面五步走，**每步都是可判定的，不靠感觉**：

| 步骤 | 判定 | 不过关就淘汰 |
|---|---|---|
| ① 红线过滤 | 只从"问题记录"里**没有 R 类命中**的条目里挑。R 类命中过又重录通过的，只认通过的那一遍 | 有 R 类未重录 → 淘汰 |
| ② 时长对齐 | 对脚本基准比偏差：该节点时长偏差 ≤ ±3 秒为佳；超过的部分必须落在脚本标注的句末留白里（各节点接缝资源见 `资料/录制前检查清单.md` 2.3） | 偏差大且不在留白里 → 淘汰 |
| ③ 接缝完整 | 检查**开头 2 秒 / 结尾 2 秒静止帧**是否录进去了（6.1 铁律 1）——这是后期拼接的唯一余量 | 缺接缝 → 补录或淘汰 |
| ④ 观感项 | 口头禅次数 = 0（R11 阈值是 ≥2 次必须补录，选片按 0 执行）；每个按钮点击前有 1 秒悬停（1.2）；等待期没有临时加词（1.4 三不要） | 有任一项 → 降级为备选 |
| ⑤ 连续性 | 和相邻节点接得上：鼠标起始位置 = 上一节点结束位置（6.1 铁律 2，对照纸上记录）；语速与前后段一致（基准 3.6 字/秒） | 接不上 → 该条与相邻条目一起重录 |

**输出**：每个节点定下 1 条，在总日志表"是否保留"列写 **`选用`**，其余写 `是`（备胎）。
**成片拼装顺序**：节点 1 → 2 → … → 9（节点 0 片头卡后期做图贴最前）。
**删除时点**：成片导出 + 三处备份完成后才允许清理未选用素材；**提交截止前一条不删**。
